HTML: що нового й справді корисного
1) Popover (нативні поповери без JS-комбайнів)

popover глобальний атрибут + Popover API дають стандартний механізм показу “плаваючого” контенту (меню, підказки, легкі діалоги) поверх сторінки. 


Чому це важливо: менше кастомного JS для позиціювання/фокуса/закриття, менше багів доступності.

2) inert (блокування взаємодії з частиною DOM)

inert робить елемент і нащадків неінтерактивними (фокус/клік/доступність). Дуже корисно для модалок, drawer’ів, “заморожених” секцій. 

3) <search> (семантика для зони пошуку)

Новий семантичний контейнер <search> для форми/контролів пошуку або фільтрації. Це не “революція”, але нормалізує семантику й доступність. 

Примітка: у HTML останні роки менше “нових тегів”, більше — платформених можливостей (атрибути, API, поведінка).

CSS: ключові фічі, які найбільше змінили підхід
A) Компонентність і керування каскадом
1) Cascade Layers — @layer

Дозволяє явно керувати пріоритетами стилів (reset → base → components → utilities), не воюючи специфічністю. 

2) Scoped styles — @scope

Дозволяє обмежити область дії набору правил (по суті “CSS-скоупінг” на рівні платформи). 

Підтримка ще не всюди ідеальна, але це важливий крок до “CSS для компонентів” без сторонніх рішень. 
caniuse.com

3) Native CSS Nesting

Вкладені селектори без Sass/LESS. Уже можна використовувати як норму в сучасних браузерах. 

B) “Справжня” адаптивність компонентів
4) Container Queries — @container (size + style queries)

Стилі залежать не від в’юпорта, а від розміру/стилів контейнера — нарешті нормально для дизайн-систем і віджетів. 

C) Селектори, що розв’язують давні болі
5) :has() (relational selector)

Дозволяє стилізувати “батька, якщо всередині/поруч щось є”. Це закриває купу сценаріїв без JS. 

D) Layout-фічі, що дозріли
6) Subgrid

Дозволяє дочірній grid “успадковувати” колонки/ряди батьківського grid — сильно спрощує складні сітки. 

E) Колір і дизайн-токени на новому рівні
7) color-mix()

Нативне змішування кольорів у CSS (з вибором color space). Корисно для тем, hover-станів, токенів. 

8) OKLCH/OKLab + relative color syntax

oklch() і відносні кольори дають більш передбачувану роботу з яскравістю/насиченістю + генерацію похідних від базового кольору. 

F) Текст і типографіка
9) text-wrap (balance/pretty/…)

Нормальні заголовки без “висячих” слів: balance для хедерів, pretty для абзаців (але може бути важчим для рендерингу). 

G) Анімації та переходи нового покоління
10) Scroll-driven animations (scroll()/view() timelines, animation-timeline, scroll-timeline-*)

Декларативні анімації, прив’язані до скролу/видимості елемента. Потужно, але ще не всюди “baseline”, тому часто як progressive enhancement. 
Chrome for Developers

11) View Transitions (API + CSS псевдоелементи)

Стандартизовані анімовані переходи між станами/сторінками (SPA/MPA). Підтримка росте, але теж варто закладати фолбек. 

12) @starting-style

Дає “стартові” значення для transition, коли елемент з’являється/отримує перше оновлення стилів (замість JS-трюків). 

H) UI/скрол і “полірування”
13) scrollbar-gutter (+ сучасні підходи до scrollbar styling)

Запобігає стрибкам layout через появу/зникнення скролбару. 

14) accent-color

Тюнінг акценту в чекбоксах/радіо/інпут-контролах, але підтримка/поведінка ще нерівномірні між браузерами. 

I) “Ще сире, але стратегічно важливе”
15) Anchor positioning (anchor-name, position-anchor, …)

CSS-якірне позиціювання для тултіпів/поповерів/контекстних меню на рівні платформи, але поки обмежена сумісність. 

Як це впроваджувати без болю (прагматично)

За замовчуванням: @layer, container queries, nesting, :has() (з перевіркою підтримки, якщо потрібні старі Safari/Android). 
caniuse.com


Progressive enhancement: scroll-driven animations, view transitions, anchor positioning, @scope, accent-color. 

Для будь-якої “нової” фічі: перевіряй MDN Baseline / сумісність або Can I use, і тримай фолбек.

Якщо скажеш, під які браузери/ринок ти реально цілитись (наприклад: “тільки latest Chrome/Safari/Edge” vs “треба iOS 15/Android 10”), я перетворю це в короткий чекліст “можна одразу / тільки з фолбеком / поки не чіпати” саме під твої вимоги.
